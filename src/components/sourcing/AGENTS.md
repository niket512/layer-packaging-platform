# Manufacturer network map
- Premium box size uses one draft input parsed into existing length/width/height values; keep entered units and centimetre submission conversion unchanged.
- Premium box drafts keep one box type and one product selection; normalise only unsent drafts, preserving historical submitted briefs.
- Catalogue photos resolve through `catalogueImage` to compressed CDN WebP assets; keep source records unchanged and reuse the resolved photo in details and attachments so browsing and enquiry handoffs avoid original downloads.
- Use local state outlines with density tiers derived only from uploaded listing counts; colors indicate reference coverage, not verified partners.
- Keep the selected map state in ManufacturerNetwork so the list link above the map preserves the selected state filter.
- Guided form is three steps (packaging, optional WhatsApp, details) defined in sourcing-form; an early valid number (PremiumBoxForm saves it as soon as it is valid) is saved as an unsubmitted chat record and drafts persist per page, while only the final submit creates an enquiry — captures contact earlier without counting partial leads as conversions.
- Catalogue quote entry combines editable added details, remaining inputs and contact in one mounted form; derive the submitted brief from current values to avoid stale edits without changing the saved-enquiry path.
- Admin funnel calculations share pure session-stage helpers with separate form/chat cohorts; later progress bypasses optional steps without fabricating views, and browsing stays optional.- Homepage box enquiry always shows `PremiumBoxForm` (old saved classic assignments are overridden; only an explicit ?form=classic shows the classic form, non-sticky); v2 rules live in `src/lib/box-enquiry.ts`, structured answers go to `requirement_submissions.details` and sessions are tagged via a form_step journey event with category form-<variant> — compares versions without new tracking schema.
